# 📝 Yapılacaklar Listesi

Günlük görevleri yönetmek için basit, hızlı ve kullanıcı dostu bir web uygulaması.

## 🚀 Nasıl Kullanıl��r

Uygulamayı doğrudan tarayıcıda açabilirsin:
- **Raw linki:** [index.html](https://raw.githubusercontent.com/79njpz7tdv-cmd/yap-lacaklar/main/index.html)

## ✨ Özellikler

- ✅ **Görev Ekleme** - Yeni görevleri hızlıca ekle
- ✅ **Görev Tamamlama** - Checkbox veya metne tıklayarak işaretle
- ✅ **Görev Silme** - "Sil" düğmesiyle kaldır
- ✅ **Otomatik Kaydetme** - Tarayıcı depolama ile veriler kaybolmaz
- ✅ **Mobil Uyumlu** - Telefonunda tam çalışıyor
- ✅ **Tema** - Yeşil renk teması ile hoş arayüz
- ✅ **Klavye Desteği** - Enter tuşu ile görev ekle

## 📱 Mobil Cihazda Kullanım

iPhone veya Android'de:
1. Tarayıcıda uygulamayı aç
2. **Paylaş** → **Ana Ekrana Ekle** seçeneğini kullan
3. Masaüstü uygulaması gibi kullan!

## 💾 Veriler Nereye Kaydedilir?

Tüm görevlerin tarayıcının local storage'ında kaydedilir. Başka cihazlara taşınmaz, kişisel verileriniz güvendedir.

## 🛠️ Teknolojiler

- **HTML5** - Yapı
- **CSS3** - Tasarım
- **Vanilla JavaScript** - İşlevsellik
- **localStorage API** - Veri depolama
